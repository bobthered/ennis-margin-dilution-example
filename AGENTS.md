# Commit message suggestions

Before finishing a task, review all uncommitted work, including staged changes,
unstaged changes, and untracked files. Suggest a concise commit message in the
final response that describes the changes reviewed. Do not commit unless asked.

The suggested commit message must always begin with exactly one of these prefixes:

- `fix: ` for a bug fix.
- `feat: ` for new functionality.
- `refactor: ` for restructuring that preserves existing behavior.

Choose the prefix that best describes the primary purpose of the changes. Use an
imperative description after the prefix.
